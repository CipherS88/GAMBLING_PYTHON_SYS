## 💻 Getting started

**1. Clone the repository:**

```bash
git clone https://github.com/CipherS88/GAMBLING_PYTHON_SYS.git
cd GAMBLING_PYTHON_SYS
```

**2. Run it:**

```bash
python main.py
```

`blackjacktesting.py` is the standalone blackjack prototype used while building it.

There are no dependencies — standard library only, Python 3.6+.
